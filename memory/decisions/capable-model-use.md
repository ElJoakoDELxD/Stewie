title: Four roles by tier: worker, manager, supervisor, advisor
status: current
date: 2026-11-17
by: the person
---
Work is split by role, each on its own tier of model, from cheapest to most capable. The worker reads and writes. The manager assigns and organizes the tasks. The supervisor is the director, who decides what is to be done. The advisor is the most capable model available, consulted when a stronger judgement is needed; when the top model is not available, the supervisor's tier serves as the advisor. The session itself runs as the manager.

Roles are tiers, not names: which model fills each is the person's configuration (the session's model, `/advisor`, and each subagent's `model`), because models change. Memory names no model to use. A model name enters memory only as a record of who wrote something, as the hook reported it then (a delegation line is the exception: it holds the alias the delegate was asked to run on), with the note that it does not say which model serves now: that is in the transcript of the current reply.

The most capable tier is consulted only when the result becomes public or cannot be undone, no bench or written criterion can check it, and its inputs exist now: the advisor rereads the whole transcript. Replaces an earlier rule that sent audits to the most capable model directly. Paraphrased, not quoted: the branch is public.
